# リモートプレイ

PCゲームの画面を共有して離れた人と一緒に遊ぶアプリ

## ダウンロード

**[RemotePlay-Setup.exe をダウンロード](https://github.com/Kawate02/remote-play-releases/releases/latest/download/RemotePlay-Setup.exe)**(いつも最新版)

## インストールのしかた

1. 上のリンクを押すと、インストーラのダウンロードが始まります
2. ブラウザに「一般的にダウンロードされていません」「危険な可能性があります」と出て止まったら、ダウンロードの一覧で次を押します
   - Chrome: 「保存」(または「危険なファイルを保存」)
   - Edge: 「…」→「保存」→「詳細表示」→「保持する」
   - 名前が `未確認 123456.crdownload` のファイルはまだダウンロードが終わっていません。開かずに、上の「保存」を押してください
3. ダウンロードした `RemotePlay-Setup.exe` を開きます
4. 「WindowsによってPCが保護されました」と出たら、「詳細情報」→「実行」を押します
5. 確認の画面は出ず、そのままインストールされて起動します(管理者権限は不要)。デスクトップとスタートメニューに「リモートプレイ」ができます

警告が出るのは、このアプリにコード署名(有料の証明書)が付いていないためです。

## 更新・アンインストール

- 新しい版は、アプリが自動でダウンロードし、次に閉じた時に入れ替わります
- アンインストールは「設定」→「アプリ」→「インストールされているアプリ」から

## 注意

[リリースページ](https://github.com/Kawate02/remote-play-releases/releases) の `latest.yml`・`.blockmap`・`Source code` は自動更新用の部品です。開く必要はありません(開くと Visual Studio やメモ帳が起動することがあります)。
